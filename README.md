# Site — Cuidadora de Idosos

Primeira versão de teste, feita com HTML, CSS e JavaScript puros.

## Como abrir
1. Extraia a pasta do ZIP.
2. Abra `index.html` no navegador. Para desenvolvimento, você também pode usar a extensão Live Server do VS Code.
3. A imagem da profissional está em `assets/foto-cuidadora.jpg`.

## Antes de publicar
Edite `js/script.js` e substitua:
- `whatsapp`: número real com código do país e DDD, apenas números.
- `instagram`: link real do perfil.
- `email`: e-mail real.

Revise também o texto em `index.html`, especialmente a apresentação, experiência e atividades oferecidas. Remova qualquer serviço que a profissional não ofereça ou para o qual não tenha a qualificação necessária.

## Estrutura
- `index.html`: conteúdo e estrutura.
- `css/style.css`: aparência e responsividade.
- `js/script.js`: menu mobile, ano automático e links de contato.
- `assets/foto-cuidadora.jpg`: foto fornecida para o site.

Esta versão não usa back-end nem banco de dados. Os links de contato precisam ser configurados antes da publicação.
